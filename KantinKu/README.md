# KantinKu

Flutter Android demo lokal: register/login/reset, cart, checkout simulasi, order dan session persisten.

```bash
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --debug
```

Daftar akun melalui Me. Tidak ada akun/password bawaan. Pembayaran dan reset berlabel DEMO, tanpa uang/email nyata.
