# KantinKu — Milestone 2

Flutter Android demo lokal: register/login/reset, cart, checkout simulasi, order dan session persisten. Baca [penjelasan lengkap](docs/KantinKu_02_Penjelasan.md).

```bash
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --debug
```

Daftar akun melalui Me. Tidak ada akun/password bawaan. Pembayaran dan reset berlabel DEMO, tanpa uang/email nyata. Browse final dan tema ada di ZIP3.

Flutter3.32.8/Dart3.8 baseline. Source telah diperiksa statis; Flutter analyzer/test/build belum dijalankan karena SDK tidak tersedia. APK belum dihasilkan.
